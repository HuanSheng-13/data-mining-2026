# 任务2：图像异常检测

## 作业要求

设计并实现图像异常检测算法，判断图片是否异常，并说明设计思路。

- 数据：`Image_Anomaly_Detection.zip`，包含 hazelnut（榛子）和 zipper（拉链）两类。
- 作业说明给出的每类训练数据为正常样本 200 张、异常样本 50 张；测试集同时包含正常和异常样本，实际读取时核对。
- 说明图像特征处理、训练时是否使用异常样本及标签、模型与判定阈值的选择方式，并评估测试效果。
- 作业未将本任务限定为仅使用正常训练样本；应清楚描述自己采用的设置。

评分项（共 25 分）：问题形式化描述 5 分、图像特征处理 5 分、模型与设计思想 10 分、效果评估 5 分。

以上为课程要求摘要，具体以老师作业说明及后续通知为准。
