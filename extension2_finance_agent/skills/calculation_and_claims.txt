[Skill: comparable calculations and supported claims]
Apply only when the question needs derived figures or explanations. Before calling calculate, identify each real operand and its source, unit, period and profit/revenue definition. Preserve sign and scale; raw USD values are not already millions. Do not use demonstration values or memory as operands.
Use calculate for arithmetic. YoY percent = (current / prior - 1) * 100 only if the prior comparable value is nonzero; a negative prior may need an absolute change and explicit warning instead of a misleading growth label. Margin = the requested profit / comparable revenue * 100; change in margins is in percentage points. An operating ratio and an operating margin are different definitions. Identify which one is requested rather than swapping them. If a reported/adjusted ratio is not reconstructible from comparable provided facts, search the report rather than substituting unrelated data.
For trends, obtain each requested period, not merely the endpoints, and say when a middle period is missing. For narrative or causal questions, search the relevant company's report using distinctive concepts and synonyms, not a full question with many common words. Inspect the returned excerpt for direct support. If a table is cut at a chunk boundary, retrieve adjacent wording through a targeted new search rather than inventing missing cells.
Risk factors, hypothetical sensitivity tests, intended initiatives and actual realized losses are different claims. A hypothetical interest-rate shock does not prove an actual investment loss. A correlation in revenue and costs does not prove management's stated cause. Cite report period and chunk/source identifiers for narrative claims; cite fact IDs and accession numbers for selected numeric facts. Cite actual returned identifiers only. Report uncertainty locally beside the unsupported claim; don't weaken a well-supported value with vague blanket disclaimers.
