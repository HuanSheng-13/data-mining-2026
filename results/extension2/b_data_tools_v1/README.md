# 拓展二任务 B 交接

共同基线为 PR #5 合并提交 `8021a16`。实现、准备工厂、配置与验证记录包含在同一个任务 B 提交中。派生索引在 `extension2_finance_agent/artifacts/data_optimized/evidence.sqlite`，可按[准备说明](../../../extension2_finance_agent/prepare/README.md)重建。基础 Agent 的模型参数、策略及提示词沿用基线配置。

| 材料 | 用途 |
| --- | --- |
| [preparation.json](preparation.json) | 构建耗时、索引大小、内容和原始输入指纹、检索参数 |
| [train_tool_comparison.json](train_tool_comparison.json) | 两套工具对相同查询的返回、来源、相关证据名次和单次调用耗时 |
| [verification.json](verification.json) | 回归测试、真实数据检查和基线 Agent 接入验证摘要 |
| [data_optimized.json](../../../extension2_finance_agent/configs/data_optimized.json) | B 独立配置，可供后续集成 |

在真实数据上构建了 9 份年报的 19,817 个证据片段和 2,439 组指标。索引约 37.3 MiB，在本机重建约 9 秒。用同一版本原始资料和环境重建后，索引 SHA-256 与 manifest 一致。基础工具的 6 项真实数据检查在优化配置下也通过。拓展二 pytest 全套 39 项通过。Windows 下可使用 `python -X utf8 -m pytest extension2_finance_agent/tests -q`，以便已有测试正确读取含中文路径的 UTF-8 日志。若系统临时目录权限有问题，可追加 `--basetemp` 并指定新的可写目录。

通过脚本客户端驱动基础 Agent 的标准调用循环，验证其能读取真实的优化工具返回和来源字段。这个接入检查没有调用模型 API。

| 训练案例 | 基础版 | 优化版 | 证据位置 |
| --- | --- | --- | --- |
| `FQA-1640147-02`，云区域覆盖 | 前五未返回包含目标短语的段落 | 第 1 项明确写到 47 个区域部署 | `1640147/snow-20250131:27974`，Item 1 |
| `FQA-1640147-06`，产品与技术 | 第 1 项同时包含两项产品线索 | 第 1 项也命中，附风险章节归属，可识别其语境 | `1640147/snow-20250131:99637`，Item 1A |
| `FQA-702165-05`，铁路经营比率 | 第 1 项大文本块包含所查数值 | 第 1 项直接给出表格行及对应的调整后列头 | `702165/nsc-20241231:89404` |
| `FQA-1640147-05`，发现收入指标并查源记录 | `sales revenue` 无候选，同一 SQL 返回 1 行 | 返回 5 个候选，同一 SQL 仍返回 1 行，并说明单位和期末 | `financial_facts.id=2509712`，accession `0001640147-25-000052` |

前三个案例都按公司和明确年报期末检索，优化版命中的定位范围已回查原 HTML。查询案例的返回与原始 SQLite 查询一致，事实期间为 2025-01-31，披露日期为 2025-03-21。该例仅核验一个来源事实。它没有覆盖整道收入趋势题所需的所有期间。

局限包括词汇差异、启发式章节和表头识别，以及 SQL 别名或聚合字段的来源判读。对比使用三个手动年报查询和一个指标案例，未运行模型作答和官方评分，因此无法推断支持率变化。准备与工具耗时分别记录，单次工具调用时间受本机文件缓存影响。基线与优化配置均可供 A 完成全量 train 对比。
