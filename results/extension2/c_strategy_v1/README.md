## 真实案例与证据

1. Moderna 收入趋势，`FQA-1682852-05`：两组给出 2022/2023/2024 收入 19.263/6.848/3.236 十亿美元及 -64.45%、-52.75% 同比，C 用同一 2025 年披露的比较数选择来源，工具数从 9 降至 7。证据为 `*/logs/001.jsonl`、`case_audit.json`，不能把 fiscal_year 当成唯一期间依据。
2. Norfolk 经营效率，`FQA-702165-05`：基础策略最终回答是未执行的 DSML 工具标记，检查器判为信息不足；C 给出 2024/2023 reported operating ratio 66.4%/76.5%，区分 adjusted 65.8%/67.4%，并实际调用 calculate。C 仍有一次多表达式参数错误，随后改为单表达式恢复。证据为 `*/logs/004.jsonl`（从 0 编号），关键 facts 847174、859736、847164、859726 已只读核对。
3. Norfolk 利润率，`FQA-702165-07`：基础策略在 16 次工具预算后将后续调用写进最终正文，没有形成可用的总结。C 也达到 16 次工具调用，但保留实际计算和来源，给出 operating margin 23.5%→33.6%、net margin 15.0%→21.6%，检查器判为支持。证据为 `*/logs/005.jsonl`。仍存在模型一次尝试把多个计算装进表达式的错误，不能称“消除工具错误”。
4. Moderna 利率敏感性，`FQA-1682852-09`：两组均支持；C 从 2 次增加到 4 次工具、耗时 6.60→10.10 秒，属于没有改善判定却增加开销的案例。其回答区分 1 个百分点利率冲击导致约 5300 万美元公允价值变化的假设与实际损益，但“期限更短”等额外解释仍需谨慎核对，自动支持不保证每句完整正确。证据为 `*/logs/002.jsonl`。

## 指标口径和限制

官方脚本以全部 37 题为分母：基础支持率 10.81%，C 为 16.22%，未作答 31 题仍计信息不足；原输出完整保留。6 题子集的 66.67% 和 100% 是另外按固定作答集合计算的分析值。两者不能混写。自动支持允许部分/间接支持，不是严格完整准确率。

本轮只有每配置一次运行，没有显著性或跨模型结论；运行顺序、服务负载和缓存会影响时延。tokens 减少 20.86%，工具调用减少 6.78%，但本轮总耗时反而增加约 1.27%，不能宣称加速。未将 token 数直接换算成账单费用；检查器返回未统一暴露完整 token 用量，不能假装已统计完整评测成本。

公共框架对“正文中的伪工具调用”没有专门失败状态，可能出现 completed 但回答无效；建议 A 在独立公共修复 PR 中完善最终回答校验。C 没有私自修改 A 的 core/ 或停止条件。本轮 train 输出保留，不能事后改正文来“修复分数”。

## 补充运行后核查

`*_trace_audit.json` 是只读日志分析。基础策略 1 次工具报错、C 2 次，因此没有证据支持“所有工具错误减少”；两组均未原样重复同一失败参数。成功计算分别 14/18 次，最终正文含已知工具标记分别 2/0 题。这些观察值不替代官方判定或人工事实检查。真实模型运行使用 Python 3.13.1，回归测试使用 Python 3.12.14；精确版本以原 run.json 为准。

人工引用核对还发现：C 的 Norfolk 答案把部分事实 ID 统一写在 2025 年 accession 下，但 847164 与 859726 实际属于 2024 年 accession。这是自动支持判定没有发现的引用缺陷，数值正确不代表引用完全正确。下一版本将明确要求按事实 ID 分别配对 accession，并限制计算器每次只有单个标量表达式；原 v1 结果保留。
