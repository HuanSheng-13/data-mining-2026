# 财务问答 Agent 最终结果

这里只保留 `configs/final.json` 对应的单一方案：带财务口径约束的工具调用 Agent。方法、数据规范、输入输出与运行命令见[工程README](../../extension2_finance_agent/README.md)。完整预测、公开模型/工具日志、运行快照、检查器设置和评分按 `train/`、`test/` 保存。

## 选择依据

此前四种组合的完整 train 对照保存在 Git 历史 `e7a8c9c`；本工作目录已移除候选代码与实验材料。选择依据是训练集支持率、工具调用成本和输出可靠性，未使用 test 反馈。最终实现沿用较有效的财务 Skill 与简单检索结构，补充相邻段落读取、只读 SQL 限制、模型工具协议恢复、引用检查以及保留两轮的最终回答阶段。索引去掉隐藏 XBRL 内容，避免检索噪声。

这里的“最佳”表示本次已验证候选中的工程选择，不表示所有模型和方法的全局最优。最终版本同时调整了提示、预算和索引，不能把变化归因于单个组件；单次模型运行也不能证明稳定的统计优势。

## 训练集验证

方法代码版本：`7445dd1`。37题全部正常完成，35题获得官方检查器支持，2题判为矛盾，支持率 **94.59%**。没有缺失答案、空答案、最终工具标记或评分 API 失败。

工具调用335次，模型调用208次，总用量2,445,985 tokens；逐题耗时合计约425.4秒。用量为服务端返回的统计，不能直接换算为账单金额。格式检查、逐题运行摘要、完整日志和文件校验值见 [train/](train/)。

两条不支持结果原样保留：

- `FQA-1373715-06`：答案依据2024年报描述2030年到期的固定利率债券，与参考答案对可转换债务的描述冲突。结构化标签名称也可能与年报实质不符，不能仅凭标签判断债务性质。
- `FQA-702165-03`：答案使用运输单位数同比增长5%，参考答案描述收入吨英里基本稳定。两者衡量口径不同；答案没有提供收入吨英里来消除歧义，不能把这一题自行改判为正确。

自动支持率是教师检查器对保存答案与参考答案的宽松一致性判定，不是严格完整正确率，不直接换算作业得分。以上分歧不修改参考答案、不修改官方标签。
