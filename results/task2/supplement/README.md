# AE补充实验

## 7. 补充：AE稳定性与跨环境复现（2026-11-19）

### 7.1 预设协议与逐次结果

在macOS ARM64、Python 3.12.14、PyTorch 2.7.1、torchvision 0.22.1、NumPy 2.3.5、SciPy 1.18.1、scikit-learn 1.7.2、Pillow 12.0.0，CPU、2线程下，固定正常划分种子42；训练种子预先取0、1、42，仅改变参数初始化和训练打乱顺序。其余保持10轮、批大小16、Adam学习率0.001、正常校准分位数0.99。下面是全部六次结果，不挑选最优种子。

| 类别 | 训练种子 | AUROC | AP | F1 | TP / FP / FN / TN |
| --- | ---: | ---: | ---: | ---: | --- |
| hazelnut | 0 | 0.63167 | 0.4499 | 0.1250 | 1 / 0 / 14 / 40 |
| zipper | 0 | 0.56458 | 0.3707 | 0.1053 | 1 / 3 / 14 / 29 |
| hazelnut | 1 | 0.63667 | 0.4491 | 0.0000 | 0 / 0 / 15 / 40 |
| zipper | 1 | 0.57083 | 0.3736 | 0.1053 | 1 / 3 / 14 / 29 |
| hazelnut | 42 | 0.63500 | 0.4494 | 0.0000 | 0 / 0 / 15 / 40 |
| zipper | 42 | 0.53125 | 0.3703 | 0.1111 | 1 / 2 / 14 / 30 |

- hazelnut：AUROC均值 0.63444，样本标准差 0.00255；F1均值 0.0417，样本标准差 0.0722
- zipper：AUROC均值 0.55556，样本标准差 0.02128；F1均值 0.1072，样本标准差 0.0034

标准差采用样本标准差（ddof=1），每类仅3个种子；它描述固定划分下的训练波动，不代表数据重采样、跨平台方差或置信区间。zipper在三次训练中均只检出1/15张异常；10轮整图平均重建误差基线的漏检问题，比本次跨环境AUROC的小幅变化更值得关注。损失下降不等同于异常排序或召回率改善，也不能据此声称AE充分训练后的上限。

### 7.2 独立重复与差异边界

另起进程独立重训种子42的zipper，47个测试分数及20个正常校准分数均逐项完全一致。新增运行与改动前本机探针的种子42测试分数一致性为 `True`。之前的1线程/2线程控制实验也逐项一致，不能据此把线程切换认定为同学复现差异的原因。

Windows原参考结果仍为AUROC=0.54375、F1=0.1053；本机种子42为AUROC=0.53125、F1=0.1111。原结果没有被替换成新结果。两套环境并不完全相同；现有证据说明本机能重复，尚未隔离跨环境差异的唯一来源。同学只提供AUROC=0.5500、F1=0.2000，无法确认其实际误判数或判断哪一方操作有误。
